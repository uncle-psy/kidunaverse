# Connector Interface Notes

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

Connector separates **Agents**, **Systems**, and **Realms**. Agent cards preserve Avatar, Ally, and Actor identity; relationship, connection, activity, Authority, and Permission are separately visible. System cards cover Google (Gmail, Meet, Calendar, YouTube), Bluesky, Telegram, and Solana with explicit prototype states.

Realm actions and invitation codes expose destination, host, Resources, expiry, limits, audience, proposed Role/access, revocation, and history. Connection or invitation does not itself establish trust, membership, Consent, Role, Authority, or unlimited access.
