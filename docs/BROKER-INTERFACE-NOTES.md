# Broker Interface Notes

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

Broker gathers wallets, Personal Vault, Realm treasuries, Themecoins, Offers, Resources, exchanges, Commitments, allocations, compute, approvals, receipts, failures, Coupons, Gifts, Rewards, and Sponsorships. Sponsor is not a separate navigation destination.

Sponsorship records Sponsor, recipient, Resource/amount, terms, expected benefit when applicable, duration, Realm rules, approval, privacy, disclosure, cancellation/revocation, and receipts. Sponsorship does not automatically create control, endorsement, private access, or promotional Permission.
