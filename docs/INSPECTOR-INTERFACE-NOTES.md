# Inspector Interface Notes

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

Inspector is the read-oriented workspace for objects, histories, provenance, version lineage, boundaries, related Signals, delivery/landing, Actions, receipts, corrections, and supersessions. Search and filters narrow the authorized view without widening visibility.

The interface explicitly distinguishes object/history, proposal/Action, Action/receipt, transmission/delivery, Delivery Landing/Semantic Landing, and visibility/verification. Missing, disputed, stale, unknown, or hidden information is not fabricated.
