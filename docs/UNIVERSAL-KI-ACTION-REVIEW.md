# Universal Ki Action Review

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

The Receiver 0.02 Ki treatment is persistent across Field and every workspace. Preview creates a reviewable proposal and never executes it. Each proposed action has an independent checkbox plus target, scope, Authority, privacy, reversibility, effect, and local/external/consequential/approval-gated classification.

Users may select all, clear all, approve selected, approve all, revise, or cancel. Revise preserves the proposal, accepts requested changes, and produces a new preview without applying anything. This prototype only applies clearly labeled local state changes and never claims an external Action occurred.
