# Creator Interface Notes

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

Creator groups creation under **Meaning** (Maps, Realms, Nodes, Media), **Agents** (Avatars, Allies, Actors, Automations), **Exchange** (Offers, Resources, Actions, DUNAs), and **Expressions**. “Agents” is a navigation group and does not reclassify Avatars.

Expression creation captures name, purpose, included material, Layout, access/privacy, Source/contributors, and provenance. Draft Preview, Rehearsal, publication review, and Live availability remain separate states. Media may be multimodal; storage, indexing, and vector loading require separate authorization.
