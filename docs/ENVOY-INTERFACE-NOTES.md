# Envoy Interface Notes

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

Envoy stages governance proposals, direct votes, delegated votes, decision markets, deadlines, mandates, spend/market limits, thresholds, revocation controls, history, outcomes, and receipts.

The Source’s direct vote remains distinct from an Envoy’s delegated Action. An Envoy may act only inside an explicit Realm, mandate, duration, budget, threshold, approval policy, and revocation policy. Prototype controls create local proposals only.
