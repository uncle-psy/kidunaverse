# Layout Types

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

- **Composed** — default WIMP interface and the grammar for Panels, Overlays, and Chrome.
- **Setting** — isometric or 2.5D spatial environment.
- **Pulse** — layered viewport showing many things in relation.
- **Graph** — Cards or boxes connected by typed relationships.
- **Theater** — focused Media presentation for watching and listening.
- **World** — full 3D environment for movement and embodied presence.
- **Reader** — reading-led documents, books, magazines, and essays with optional audio/video.
- **Game** — playable rules, choices, challenges, feedback, scoring, and shared or solo state.

Each Expression selects one Layout in Creator. A Layout presents material; it does not create truth, membership, Authority, or Permission.
