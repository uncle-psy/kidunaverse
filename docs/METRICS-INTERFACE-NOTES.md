# Metrics Interface Notes

> Status: Layout Kit/product proposal. This document does not update the Kiduna Taxonomy Canon.

Metrics is a purpose-led view of participation, contribution, livelihoods, and shared resources. It is not a conventional analytics dashboard and should never reduce a living movement to one score.

## Member-facing model

The interface leads with **Purpose**: why the work exists and what it hopes to make possible. Members can look across Kiduna or choose a movement organized around a particular purpose. The interface deliberately uses “movement,” “mission,” “purpose,” “people,” “work,” and “shared resources” in place of internal legal, protocol, or implementation terminology.

The network view combines:

- people taking part;
- people actively contributing;
- value moving in USD;
- payments to contributors for work, rewards, and fees;
- treasuries and other shared resources;
- participation growth;
- a participation trend;
- a value-flow breakdown; and
- a comparison of movements by purpose, participation, contribution, volume, contributor payments, and momentum.

Contribution includes paid and unpaid work, but the interface keeps payments visible so participation does not become a euphemism for free labor. Shared resources are shown alongside contributor earnings rather than in place of them.

## Data boundary

All numbers in this release are illustrative prototype data. Both the Field summary and Metrics workspace label the view accordingly. Production data must identify its source, reporting period, currency handling, update time, privacy boundary, exclusions, and correction path before the prototype label is removed.

Purpose is not a performance score. Growth does not establish health, truth, legitimacy, or importance. The view should preserve context and allow a member to inspect how each number was calculated.
